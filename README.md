# Weather-Dashboard
# Project Name: Weather Dashboard

## Features:
	•	Search Bar: Input a city to get real-time weather data.
	•	API Integration: Fetch data from OpenWeatherMap API.
	•	Data Display: Show temperature, humidity, wind speed, and weather description.
	•	Icons: Display weather icons from API data.
	•	Units Toggle: Switch between Celsius and Fahrenheit.
	•	Local Storage: Save last searched city and load it on page refresh.
	•	Responsive Design: Works on mobile and desktop.

## Required Tools & Skills:
	•	HTML: Basic structure with a search bar and results section.
	•	CSS: Flexbox for layout, minimal styling.
	•	JavaScript:
	•	Fetch API for asynchronous data retrieval.
	•	DOM Manipulation.
	•	Event Handling.
	•	Local Storage.
